# Desafio legaplan

Este projeto é um __desafio técnico__ para a vaga de __desenvolvedor Front-end Jr__, onde foi pedido para criar uma Todo List baseado no design proposto no __Figma__ utilizando as técnologias: __React, Next JS e Sass.__

#react #next #sass

- __Link para o acesso:__ https://desafio-legaplan-ten.vercel.app/

## Desenvolvendo
Neste projeto trabalhei com as seguintes técnologias:

- React
- Next JS
- Sass
- Css
- Typescript
- Hooks e Providers
- Definição de rotas
- Formatação de data
- LocalStorage
- Server components e Client components

## Comandos iniciais
```
npm install
```
```
npm run dev
```
